# Always Push Changes Rule

## Mandatory Workflow
Before presenting the final response to the user for any code or asset modifications:
1. Stage all completed changes (`git add .`).
2. Commit with a clear, descriptive message (`git commit -m "..."`).
3. Push to the remote repository on the active branch (`git push`).
4. Provide the user with the final response, confirming the pushed commit and remote status.
